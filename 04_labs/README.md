# Labs

Este directorio alojará especificaciones de laboratorios cuando su tamaño justifique separarlas del Curriculum.

Por ahora, las fuentes canónicas son:

- Programming Foundations: [`PF.5 Laboratorios`](../02_curriculum/01_programming_foundations.md#pf5-laboratorios)
- Computer Science Foundations: [`CS.5 Laboratorios`](../02_curriculum/02_computer_science_foundations.md#cs5-laboratorios)

El Study Guide prepara para los labs, pero no los sustituye. Una explicación comprendida sin evidencia ejecutable no aprueba el gate.
